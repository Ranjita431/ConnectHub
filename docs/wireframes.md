## 5. Wireframe Notes

- Desktop layouts use a sidebar for application navigation.
- Mobile layouts use compact navigation at the bottom.
- The landing page has a separate public navigation layout.
- Page content must remain readable at smaller screen sizes.
- Cards and sections should use consistent spacing.
- These layouts are structural plans, not final UI designs.
- All user names and sample content used during development must be fictional.
